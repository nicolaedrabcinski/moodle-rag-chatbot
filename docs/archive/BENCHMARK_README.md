## Быстрый старт

### Вариант 1: ТОП-5 рекомендованных моделей (рекомендуется)

```bash
# Автоматически скачать ТОП-5 моделей
./benchmark_quick_setup.sh
```

Включает:
1. 🇨🇳 **Qwen 2.5 7B** - Лучшая для русского
2. 🦙 **Llama 3.1 8B** - Универсальная
3. 🔮 **Mistral 7B** - Быстрая
4. 💎 **Gemma 2 9B** - От Google
5. 🔬 **Phi-3.5 Mini** - Компактная

### Вариант 2: Выбор моделей вручную

```bash
# Посмотреть список всех доступных моделей
./models_for_benchmark.sh

# Скачать выбранные модели
./benchmark_download_models.sh

# Или скачать конкретную модель
huggingface-cli download Qwen/Qwen2.5-7B-Instruct
```

### Запуск бенчмарка

```bash
# 1. Создать тестовые вопросы (11 вопросов разной сложности)
./benchmark_create_questions.sh

# 2. Запустить бенчмарк (ВНИМАНИЕ: займет 2-3 часа!)
./benchmark_run.sh

# 3. Посмотреть результаты с анализом
./benchmark_analyze.sh
```

Что происходит:
1. Для каждой модели:
   - Останавливает текущий vLLM
   - Запускает новую модель в Docker
   - Перезапускает backend с новой конфигурацией
   - Тестирует все вопросы (11 штук)
   - Сохраняет результаты

2. Тестовые вопросы:
   - **Simple** (3): простые определения (например: "Что такое философия?")
   - **Medium** (3): сравнения и концепции
   - **Complex** (3): глубокий анализ
   - **RAG specific** (2): тесты retrieval

## Рекомендации по выбору

### Для production (высокая нагрузка)

✅ **Рекомендуется:** Gemma-2-2B или Phi-3.5-mini
- Плюсы: очень быстро (8-10s), мало VRAM
- Минусы: меньше деталей в сложных вопросах
- Когда: много пользователей одновременно

### Для сложных задач

✅ **Рекомендуется:** Qwen2.5-7B или Llama-3.1-8B
- Плюсы: лучшие ответы, больше деталей
- Минусы: медленнее (18-20s)
- Когда: качество важнее скорости

### Для русского языка

✅ **Рекомендуется:** Qwen2.5-7B (лучший выбор)
- Плюсы: отличная поддержка русского
- Альтернативы: Mistral-7B, Yi-1.5-9B

### Универсальный выбор

✅ **Рекомендуется:** Qwen2.5-7B
- Баланс скорость/качество
- Отличная поддержка русского
- ~18GB VRAM

## Настройка бенчмарка

### Изменить список моделей

Отредактируйте [benchmark_run.sh](benchmark_run.sh#L10-50):

```bash
# Раскомментируйте нужные модели
QWEN_MODELS=(
    "Qwen/Qwen2.5-7B-Instruct"
    "Qwen/Qwen2.5-3B-Instruct"
    "Qwen/Qwen2.5-14B-Instruct"  # ← раскомментировать
)

LLAMA_MODELS=(
    "meta-llama/Meta-Llama-3.1-8B-Instruct"
    "meta-llama/Llama-3.3-70B-Instruct"  # ← добавить
)
```

### Добавить свои вопросы

Отредактируйте [benchmark_questions.json](benchmark_questions.json):

```json
{
  "simple": [
    {
      "question": "Ваш вопрос",
      "category": "definition",
      "expected_keywords": ["ключевые", "слова"]
    }
  ]
}
```

### Настроить параметры vLLM

В [benchmark_run.sh](benchmark_run.sh) функция `start_vllm_model`:

```bash
--gpu-memory-utilization 0.9  # 0.85 для консерватизма
--dtype half                   # или auto, float16
--max-model-len 8192          # или 4096 для экономии VRAM
--tensor-parallel-size 1      # 2 для multi-GPU
```

## Troubleshooting

### Модель не помещается в VRAM

```bash
# Попробуйте INT8 квантизацию
--quantization int8

# Или уменьшите max-model-len
--max-model-len 4096
```

### Backend не запускается

```bash
# Проверьте логи
tail -f backend_benchmark.log

# Проверьте порт
lsof -i :8888
```

### vLLM не запускается

```bash
# Проверьте Docker
docker logs fcim-llm-server

# Проверьте GPU
nvidia-smi
```

## Ручное тестирование

Если нужно протестировать только одну модель:

```bash
# 1. Запустить модель в vLLM (см. скрипт)
docker run -d --rm --name fcim-llm-server --gpus all \
  -p 8001:8000 \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  vllm/vllm-openai:latest \
  --model Qwen/Qwen2.5-7B-Instruct \
  --dtype half

# 2. Обновить .env
sed -i 's|LLM_MODEL=.*|LLM_MODEL=/models/Qwen--Qwen2.5-7B-Instruct|' .env

# 3. Перезапустить backend
pkill -f uvicorn
source .venv/bin/activate
uvicorn src.api.main:app --host 0.0.0.0 --port 8888 &

# 4. Тест
./test_speed.sh
```

## Экспорт результатов

Результаты сохраняются в JSON и могут быть легко экспортированы:

```bash
# В CSV
python3 << EOF
import json, csv
with open('benchmark_results/summary.json') as f:
    data = json.load(f)
with open('results.csv', 'w') as f:
    writer = csv.writer(f)
    writer.writerow(['Model', 'Avg Time', 'Avg Length'])
    for model, stats in data.items():
        writer.writerow([model, stats['avg_time'], stats['avg_length']])
EOF

# В Markdown таблицу
python3 benchmark_to_markdown.py > RESULTS.md
```
