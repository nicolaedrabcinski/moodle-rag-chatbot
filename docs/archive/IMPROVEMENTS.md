### 3. Более точные и частые обновления прогресса

#### Backend изменения:
**Файл**: `src/services/document_processor.py`

**Увеличена частота обновлений OCR** (строки 267-285):
```python
# Было: обновление каждые 5 страниц
if i % 5 == 0:
    logger.info(f"OCR progress: {i}/{len(images)} pages")

# Стало: обновление на КАЖДОЙ странице + SSE-прогресс
logger.info(f"📄 OCR страница {i}/{len(images)}")
if self.progress_tracker:
    progress_percent = 30 + int((i / len(images)) * 25)
    self.progress_tracker.emit(
        'progress',
        f'📖 OCR обработка: страница {i}/{len(images)}',
        progress_percent,
        step=f'ocr_{i}'
    )
```

**Результат**:
- Прогресс обновляется на каждой странице OCR
- Пользователь видит: "📖 OCR обработка: страница 3/50"
- Прогресс-бар плавно движется от 30% до 55% в процессе OCR
- Детальные логи в real-time консоли

#### Frontend изменения:
**Файл**: `frontend/index.html`

- **Плавные анимации прогресс-бара**: CSS transition 0.3s ease-in-out
- **Animated log lines**: Каждая новая строка лога появляется с анимацией
- **Детальная информация**: Показывается текущий этап и процент
- **Цветовая индикация**: 
  - Синий = в процессе
  - Зелёный = успех
  - Красный = ошибка

### 4. Система прогресса

#### Этапы обработки:
1. **0-10%**: Загрузка на сервер (📤)
2. **10-30%**: Сохранение файлов (💾)
3. **30-55%**: OCR обработка (📖) - ОБНОВЛЯЕТСЯ КАЖДУЮ СТРАНИЦУ
4. **55-60%**: Разбиение на фрагменты (✂️)
5. **60-80%**: Генерация embeddings (🧮)
6. **80-95%**: Сохранение в Qdrant (💾)
7. **95-100%**: Завершение (✅)

## 🚀 Как использовать

### Загрузка документов:
1. Введите название курса
2. Выберите или перетащите PDF файлы
3. Нажмите "Загрузить файлы"
4. Наблюдайте за детальным прогрессом в real-time

### Удаление курса:
1. Найдите курс в списке
2. Нажмите кнопку 🗑️
3. Подтвердите удаление
4. Курс будет удалён с диска

### Чат с AI:
1. Выберите курс или "Все курсы"
2. Введите вопрос
3. Получите ответ с источниками
