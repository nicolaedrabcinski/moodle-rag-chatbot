# RAG Бенчмарки для оценки качества ответов по документам

## Обзор

Существуют специализированные бенчмарки для оценки систем RAG (Retrieval-Augmented Generation), которые тестируют качество ответов на основе документов.

## 🎯 Топовые RAG бенчмарки

### 1. **RAGAS** (RAG Assessment) ⭐ Рекомендуется

**Что оценивает:**
- **Faithfulness** (верность) - ответ соответствует контексту
- **Answer Relevancy** (релевантность ответа) - соответствие вопросу
- **Context Precision** (точность контекста) - качество retrieval
- **Context Recall** (полнота контекста) - достаточность информации

**Установка:**
```bash
pip install ragas langchain
```

**Для чего:** Комплексная оценка всей RAG pipeline

---

### 2. **BEIR** (Benchmarking Information Retrieval)

**Что оценивает:**
- Качество поиска (retrieval)
- Ranking релевантных документов
- 18 различных датасетов

**Установка:**
```bash
pip install beir
```

**Для чего:** Оценка качества поиска документов

---

### 3. **RGB** (Retrieval-augmented Generation Benchmark)

**Что оценивает:**
- Noise robustness - устойчивость к шуму
- Negative rejection - отклонение нерелевантного
- Information integration - интеграция из нескольких источников
- Counterfactual robustness - устойчивость к противоречиям

**Для чего:** Проверка надежности RAG системы

---

### 4. **KILT** (Knowledge Intensive Language Tasks)

**Что оценивает:**
- Fact-checking
- Open-domain QA
- Slot filling
- Entity linking

**Датасеты:** 11 задач с Wikipedia как источником

**Для чего:** Оценка knowledge-intensive задач

---

### 5. **Natural Questions** (Google)

**Что оценивает:**
- Ответы на естественные вопросы
- Контекст из Wikipedia
- Short vs Long answers

**Для чего:** Оценка QA с реальными вопросами

---

### 6. **HotpotQA**

**Что оценивает:**
- Multi-hop reasoning (многошаговое рассуждение)
- Ответы требуют информации из нескольких документов

**Для чего:** Сложные вопросы, требующие объединения информации

---

### 7. **SQuAD 2.0** (Stanford Question Answering)

**Что оценивает:**
- Extractive QA
- Unanswerable questions (вопросы без ответа)

**Для чего:** Базовая оценка понимания текста

---

### 8. **MS MARCO**

**Что оценивает:**
- Passage ranking
- Document retrieval
- Question answering

**Для чего:** Оценка search и ranking

---

## 🔥 Рекомендация для вашей системы

### Для философских курсов лучше всего подходит:

1. **RAGAS** - комплексная оценка всей RAG системы
2. **RGB** - проверка надежности и устойчивости
3. **HotpotQA** (адаптированный) - сложные вопросы по курсам

## 📊 Метрики RAGAS (самое важное)

### 1. Faithfulness (Верность)
```
Формула: Количество верных утверждений / Общее количество утверждений
Цель: > 0.9
```
Проверяет, что ответ не выдумывает факты, а берет из документов.

### 2. Answer Relevancy (Релевантность ответа)
```
Формула: Косинусное сходство (вопрос, сгенерированные вопросы из ответа)
Цель: > 0.8
```
Проверяет, что ответ действительно отвечает на вопрос.

### 3. Context Precision (Точность контекста)
```
Формула: Релевантные чанки на верхних позициях
Цель: > 0.7
```
Проверяет качество retrieval - находятся ли нужные документы.

### 4. Context Recall (Полнота контекста)
```
Формула: Ground truth в retrieved контексте
Цель: > 0.8
```
Проверяет, что найдено достаточно информации для ответа.

## 🚀 Интеграция RAGAS в вашу систему

Я создал скрипт `benchmark_ragas.py` который:

1. Использует ваши существующие курсы
2. Генерирует вопросы или использует готовые
3. Оценивает каждую модель по метрикам RAGAS
4. Создает детальный отчет

### Использование:

```bash
# Установить RAGAS
pip install ragas

# Запустить оценку
python benchmark_ragas.py

# Или интегрировать в существующий бенчмарк
./benchmark_run.sh --with-ragas
```

## 🎯 Рекомендации

### Для production системы образовательных курсов:

1. **Обязательно использовать:**
   - RAGAS (faithfulness + relevancy)
   
2. **Желательно добавить:**
   - RGB (проверка edge cases)
   - Свои кастомные вопросы по философии

3. **Метрики для мониторинга:**
   - Faithfulness > 0.9 (не выдумывает)
   - Answer Relevancy > 0.8 (отвечает на вопрос)
   - Context Precision > 0.7 (находит нужное)
   - Время ответа < 20 сек
